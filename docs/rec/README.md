# rec/ — video explicativo

Este directorio contiene el video asciinema de **Curso ESP32 Riego** y el reproductor
que se usa en la página del proyecto.

- `curso-esp32-riego.cast`: grabación original (asciicast v2).
- `curso-esp32-riego.cast.js`: los eventos embebidos para el reproductor inline.
- `player.js` / `player.css`: reproductor reutilizable.

Duración: 2:54. Los fragmentos de código son reales y
corresponden a los archivos y líneas indicados en el video.
