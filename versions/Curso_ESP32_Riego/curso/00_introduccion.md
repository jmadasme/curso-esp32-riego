# 🌱 Curso: Riego Inteligente ESP32-S3

## Del Hotspot al Riego Autónomo con IA Climática

**Duración:** 15 horas (40% teoría, 60% práctica)
**Nivel:** Intermedio
**Formato:** Presencial / Online guiado

---

## 🎯 ¿A Quién Va Dirigido Este Curso?

Este curso ha sido diseñado para:

- **Estudiantes y makers** apasionados por la electrónica y el IoT que quieren llevar sus proyectos al siguiente nivel
- **Agricultores y horticultores** que buscan automatizar el riego de sus cultivos de forma inteligente y económica
- **Aficionados a la programación** que desean aprender a programar ESP32 con proyectos prácticos y útiles
- **Profesionales del riego** que quieren incorporar tecnología IoT a sus instalaciones

Si te apasiona la tecnología, la agricultura y quieres construir algo que realmente funcione y sirva, **este curso es para ti**.

## 📋 Prerrequisitos

Para aprovechar al máximo este curso necesitas:

| Conocimiento | Nivel requerido |
|-------------|-----------------|

| Redes | Conceptos básicos de WiFi (SSID, contraseña) |

## 🚀 ¿Qué Aprenderás?

Al finalizar este curso serás capaz de:

### Habilidades Técnicas

| # | Habilidad | Descripción |
|---|-----------|-------------|
| 1 | **Programación ESP32** | Dominarás el framework Arduino para ESP32-S3 |
| 2 | **Modos WiFi** | Configurarás AP, STA y modo dual AP+STA |
| 3 | **Captive Portal** | Implementarás tu propio portal cautivo con DNS spoofing |
| 4 | **Servidores Web** | Crearás interfaces web responsive alojadas en el ESP32 |
| 5 | **Persistencia EEPROM** | Guardarás y recuperarás configuración tras reinicios |
| 6 | **Consumo de APIs REST** | Consultarás OpenWeatherMap y parsearás JSON |
| 7 | **Control de Relés** | Manejarás cargas de alta potencia (bombas de agua) |
| 8 | **Sistemas de Tiempo Real** | Implementarás schedulers y timers no bloqueantes |

### Proyecto Final

Construirás un **sistema de riego automatizado completo** con:

- ✅ Hotspot WiFi con portal cautivo
- ✅ Interfaz web atractiva y responsive
- ✅ 4 horarios de riego programables
- ✅ Verificación climática (anti-lluvia)
- ✅ Persistencia de configuración
- ✅ Control de bomba por relé
- ✅ Monitoreo en tiempo real

## 🛒 Material Necesario

### Componentes Electrónicos

| Componente | Especificación | Costo aprox. |
|------------|---------------|-------------|
| **ESP32-S3** | Cualquier placa ESP32-S3 (DevKit C1, etc.) | $8-15 USD |
| **Módulo Relé** | 1 o 2 canales, 5V, 10A | $3-5 USD |
| **Bomba de agua** | 12V DC (opcional, puedes simular con LED) | $5-15 USD |
| **Fuente de poder** | 5V 2A para ESP32 + 12V para bomba (o fuente dual) | $5-10 USD |
| **Cables** | Jumper wires, protoboard, tornillos | $3-5 USD |
| **LED + resistencia** | 220Ω para simular bomba (opcional) | $1 USD |

> 💡 **¿No tienes bomba de agua?** Durante el curso usaremos un LED como simulador. Puedes añadir la bomba más tarde.

### Software
- **Arduino IDE** (v2.x recomendada) o **PlatformIO**
- **Librerías**: ESP32 board package, ArduinoJson v6
- **Cuenta gratuita** en [OpenWeatherMap](https://openweathermap.org/api) (para API Key)
